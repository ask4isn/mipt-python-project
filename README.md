# The International Insights

## Описание проекта
**The International Insights** — это инструмент для сбора и анализа статистики по турниру The International (Dota 2) прошлых лет, с основным акцентом на команды и игроков. Проект позволяет анализировать выступления команд и их игроков, а также проводить поверхностный анализ (без машинного обучения).

## Реализуемый функционал
1. **Статистика команд**: Пользователь сможет просматривать статистику по командам, матчам, составы команд, выбор героев, а также место команды на турнире.
2. **Статистика игроков**: Для каждого игрока доступны данные по его личной статистике, включая выбранных героев, золото и опыт в минуту, убийства, смерти, ассисты и другие основные показатели.
3. **Анализ пиков героев**: Возможность анализировать, какие герои пикались командами и игроками, как часто, и с какими результатами.

## Архитектура
Проект разделен на следующие компоненты:

- **TeamStats** — класс для анализа статистики команд, состава команды, пиков героев и места на турнире.
  - Методы: 
    - `get_team_results()` — возвращает количество побед и поражений команды.
    - `get_team_composition()` — возвращает текущий состав команды.
    - `get_hero_picks()` — возвращает частоту пиков героев командой.
    - `generate_report()` — создает отчет о результатах команды и популярных пиках героев.
    - `plot_results()` — визуализирует соотношение побед и поражений.
    - `plot_hero_picks()` — визуализирует частоту пиков героев командой.
  - Атрибуты: `team_data`, `place`

- **PlayerStats** — класс для анализа статистики игроков, включая их выступления на героях и основные показатели.
  - Методы: 
    - `get_player_stats()` — возвращает средние показатели KDA (убийства, смерти, ассисты).
    - `get_player_hero_performance()` — возвращает средние значения золота и опыта в минуту для каждого героя.
    - `generate_report()` — создает отчет по статистике игрока и его производительности на героях.
    - `plot_kda()` — визуализирует KDA статистику игрока.
    - `plot_hero_performance()` — визуализирует производительность игрока на выбранных героях.
  - Атрибуты: `player_data`

- **HeroTrends** — класс для анализа тенденций пиков героев и их комбинаций в матчах.
  - Методы:
    - `analyze_hero_picks()` — анализирует частоту пиков героев.
    - `analyze_hero_combinations()` — анализирует частоту комбинаций героев, выбранных в одном матче.
    - `generate_report()` — создает отчет о популярных пиках героев и комбинациях.
    - `plot_hero_popularity()` — визуализирует популярность героев.
    - `plot_hero_combinations()` — визуализирует частоту комбинаций героев.
  - Атрибуты: `hero_data`

- **MatchStats** — новый класс для анализа данных матчей, включая идентификаторы команд, общий счет убийств и победителя.
  - Методы:
    - `get_match_summary()` — возвращает краткое резюме матча, включая счет и победителя.
  - Атрибуты: `team1`, `team2`, `kills_team1`, `kills_team2`, `winner`
